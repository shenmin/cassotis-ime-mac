Cassotis IME - 言泉输入法 · macOS @VERSION@

此镜像包含安装器。双击“言泉输入法安装器”，然后点击“安装”。
安装完成后，点击“打开键盘设置”：
系统设置 → 键盘 → 文字输入 → 编辑 → + → 中文（简体）→ 言泉输入法 → 添加。
如果已经添加过，直接从菜单栏的输入菜单选择言泉输入法 即可。
选中时显示彩色言泉 logo。输入 nihao，再按空格，可试打“你好”。

安装和使用不需要终端、Free Pascal、Xcode、Python 或下载模型。
支持 Apple Silicon（M 系列芯片），最低系统目标 macOS 14。
升级保留设置与学习记录；安装失败会尝试恢复原应用。

卸载：先在上述系统输入源列表中移除言泉输入法，再打开本安装程序并点击“卸载…”。
设置和学习记录会保留。

如果设置中已有言泉输入法，菜单栏却没有，请移除该输入源后重新添加。
从旧版本升级后，若输入菜单仍显示旧名称，保存工作后退出登录并重新登录可刷新系统缓存。

正式发布的安装包使用 Developer ID 签名并完成 Apple 公证。
文件名带 -local 的包仅供本机开发使用。
