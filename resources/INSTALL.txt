Cassotis IME - 言泉输入法 · macOS @VERSION@

这是已编译的完整安装包，包含简繁词库和本地模型。
安装和使用不需要 Free Pascal、Xcode、Lazarus、Python，也不需要下载模型。
适用于 Apple Silicon（M 系列芯片）。最低系统目标 macOS 14；已实测 macOS 26.6.2。

安装和启用

1. 双击 DMG，打开其中的“言泉输入法安装器”，点击“安装”。
   安装程序显示进度，并自动向 macOS 请求启用。不需要终端或输入命令。
2. 如果 macOS 弹出启用确认，点击“允许”。安装器核实启用结果后显示“安装完成”。
   若显示“已安装，尚未启用”，可点击“重试启用”，或打开键盘设置手动添加：
   “文字输入（或文本输入）→ 编辑 → + → 中文（简体）→ 言泉输入法”。
3. 点击菜单栏当前输入法图标（例如“A”或“拼”），选择言泉输入法，即可开始输入。
   选中时显示彩色言泉 logo。如果升级前已经添加过，通常直接选用即可。
4. 如果添加列表中暂时找不到言泉输入法，保存工作后退出登录，再登录并添加。

另附 ZIP 是开发者部署包：完整解压后双击 Install.command，完成文件安装后在键盘设置中添加输入源。
普通用户推荐使用 DMG 中的图形安装程序。
从旧版本升级后，若输入菜单仍显示旧名称，保存工作后退出登录并重新登录可刷新系统缓存。

安装会更新当前用户的输入法并备份旧应用。原有词库学习记录和设置会保留；
如果以前改过输入模式或双拼方案，升级后仍使用原设置。

若升级或重新安装后列表中有言泉输入法，输入菜单却没有它，请在系统设置中选中言泉输入法，
点击“-”移除这个输入源，再通过“+ → 中文（简体）→ 言泉输入法”重新添加。
这会刷新系统启用状态和菜单顺序，不会删除输入法的学习记录或设置。
更新后若仍看到旧的大图标，请退出“系统设置”应用（Command+Q），然后重新打开。
仅关闭“编辑”窗口可能仍会使用系统设置进程缓存的旧图标。

首次试用（约 5–10 分钟）

先打开一个空白的“文本编辑”文稿，在言泉输入法的输入菜单中打开“设置…”，
确认使用简体、全拼，并切到中文模式。然后依次尝试：

1. 输入 nihao，再按 Space，应提交“你好”一次。
2. 输入 shi，用数字选词，用 - / = 翻页，检查候选与所选文字是否一致。
3. 输入 nihao 后用 Backspace 编辑；另试 Escape 取消、Enter 提交拼音原文。
4. 单独按下并释放 Shift 切到英文，输入 hello；再按 Shift 切回中文。
5. 出现独立补全提示时按 Tab，检查补全文字和光标位置，确认没有重复提交。
6. 在设置里切换简繁、每页候选数、主题和字号，检查预览同步变化，再输入几个常用词。
7. 在文本编辑、浏览器输入框和你常用的聊天或编辑软件中切换输入。
   特别检查：输入一半时切换文本框，文字是否丢失、重复或出现在错误的位置。
8. 重新选择言泉输入法 后立即输入 nihao 并按 Space，检查首字母是否完整。

之后用它输入几段你平时会写的文字，留意候选准确率、卡顿、漏键和组合串残留。
发现问题时记录：应用名称、输入的拼音、按键步骤、预期文字和实际结果。
更完整的按键与设置说明见 CONFIGURATION.md。

卸载

先在“系统设置 → 键盘 → 文字输入 → 编辑”中选中言泉输入法，点击“-”移除输入源，
然后打开 DMG 中的“言泉输入法安装器”，点击“卸载…”。
ZIP 部署包也提供 Uninstall.command。应用会移出输入法目录，学习记录和设置保留。
