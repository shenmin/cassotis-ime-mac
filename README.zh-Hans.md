Cassotis IME macOS 版（言泉输入法 macOS 版）是一款面向 Apple 芯片 Mac 的实验性中文拼音输入法。原生 InputMethodKit / AppKit 前端通过进程间通信连接 Free Pascal 编写的独立引擎进程；核心引擎移植自 [Cassotis IME Windows 版](https://github.com/shenmin/cassotis-ime)，基础词库由 [Cassotis Lexicon](https://github.com/shenmin/cassotis-lexicon) 构建。候选排序由自研字符级语言模型驱动，全程在本机 CPU 上运行。无广告、无捆绑软件，不上传任何输入内容，词库、设置与用户学习数据均保存在本地。

当前正式版为 macOS 2.9.0（build 10），对标 Cassotis IME 与 Cassotis Lexicon v2.9.0，支持搭载 Apple 芯片、运行 macOS 14 及以上的设备。下载 [v2.9.0 安装包](https://github.com/shenmin/cassotis-ime-mac/releases/download/v2.9.0/cassotis-ime-macos-2.9.0-arm64-installer-signed.dmg)或查看[更新说明](https://github.com/shenmin/cassotis-ime-mac/releases/tag/v2.9.0)；产品概览见[官网](https://www.yanquan.org/mac)，已验证环境与已知限制见 [COMPATIBILITY.md](COMPATIBILITY.md)，历次版本演进见下文[版本历史](#版本历史)。

项目当前重点：
- 与 Windows 版保持版本同步，并在同一套基准测试集上核验排序结果；
- 基于 macOS 公开的 InputMethodKit 与 AppKit 接口实现，无需“辅助功能”或“输入监控”权限；
- 提供经 Apple 签名与公证的离线安装包，无需联网或 GPU。

## 名称来源
英文名 **Cassotis** 源自古希腊 Delphi 神庙内的圣泉。相传女祭司皮媞亚（Pythia）在传达神谕前会饮用泉水以获得灵感；圣泉由此象征预言与话语的源头，也呼应了核心引擎源自 Delphi 语言的背景。

中文名 **言泉** 既对应 Cassotis“预言之泉”的本义，也取“言如泉涌”之意，寓意流畅自然的输入体验。

## 主要特性
- **原生输入法**：基于 InputMethodKit 与 AppKit 实现，候选窗不会抢占当前应用的输入焦点。支持在原生文本框、WebKit、Chrome、Electron 及终端中进行拼音组合、分段选词与上屏；在密码框中保持系统默认的安全输入机制。
- **候选窗**：默认采用双行布局：首行单行展示最多 9 个编号候选词，次行为常驻 Tab 补全栏（右侧显示图标与版本号）。翻页时可展开为三行候选，数字键与空格键选择当前行候选，鼠标可直接点击任意可见行。单音节输入支持翻页浏览全部同音单字（含候选超过 256 个的读音）；点击用户自造词右侧的红色 `×` 即可删除该词。内置 8 套配色，字号支持 12 至 32 点（默认 14 点）并可实时预览。候选窗默认固定在本次输入起点，可在“外观”页改为跟随光标；支持开启 `;` 和 `'` 选择第 2、3 个候选（默认关闭，双拼模式下作韵母键时优先）。右键点击候选窗可呼出状态切换、设置与关于菜单，且不中断当前拼音输入。 竖排时一个候选占一行，上下键逐词选择。
- **中英文切换**：单击 Shift 切换中英文，光标旁会短暂弹出带图标的“中/英”状态气泡（可在“外观”页关闭）；切换至言泉输入法或在英文模式下聚焦输入框时也会给出提示。支持改用 Caps Lock 切换（目前不区分短按与长按，启用前请参阅[配置说明](CONFIGURATION.md)），默认按应用独立记忆中英文状态。按住修饰键期间若触发其他按键或鼠标点击，不会误触切换；前端仅比对系统事件计数，不读取其他按键内容。
- **英文识别**：在中文全拼半角模式下，常见英文词与专有名词（如 `pro`、`markdown`、`Effie`）、含大写字母的输入及曾按英文上屏的词条，会保留大小写排在编号候选之前。若输入不构成完整中文拼音，默认选中英文并可按空格直接上屏；若同时存在中文读法（如 `bug`、`mac`），则由语言模型结合上文判断优先顺序。可用方向键或鼠标切换英文与中文候选，中文候选编号保持不变；选择英文上屏会记录偏好，但不写入用户词库。默认开启，可在设置中关闭；双拼模式仍按中文规则处理。
- **一键补全**：Tab 补全栏每次仅展示一条高置信度续写建议，按配置的补全键即可上屏。用户词、基础词库精确匹配词及经离线筛选的强转移搭配会即时显示，随后由语言模型结合光标前上文在后台重排。长句输入时可补全当前词或续写后续短语，把握不足时不提示。模型预测结果以主题强调色显示，已输入拼音的直接拼接则使用普通文字颜色。古诗词支持从开头几个音节补全，完整输入上句后还可提示下句（如“春眠不觉晓，处处闻啼鸟”）。
- **长句**：基于词库约束的路径搜索生成整句候选（如 `womenjintian` → `我们今天`），同时保留前缀候选供分段上屏。语言模型在整句候选中择优，并在简繁体、全拼及双拼模式下结合输入拼音与光标前上文，自动修正整句中的少量同音错字。
- **短词**：多个同音精确候选竞争时，由语言模型结合上文与通用语料词频综合排序；无上文时兼顾通用词频与日常对话高频词保护，避免生僻词或书面词挤占常用首选。有上文时，单音节同音字同样由语言模型结合语境排序。
- **短语**：简繁体模式下，输入词库未收录的三至五音节短语（如 `jiuguize` → `旧规则`）时，引擎会先组合词库词条生成整句草稿，由语言模型结合光标前上文选出最通顺的方案并做同音纠错；若多个方案得分接近，首选后最多再附带两个备选短语。
- **拼音方案**：支持全拼及 7 种双拼方案（微软双拼、小鹤双拼、自然码双拼、搜狗双拼、紫光双拼、拼音加加和智能 ABC），共用候选排序与用户学习数据；支持逐项配置模糊音、首字母简拼（如 `jt` → `今天`），以及用 `v` 输入 `ü`（`lv`、`nv`，兼容 `lue`/`nue` 和 `jv`/`qv`/`xv`）。
- **词库与学习**：简体基础词库、繁体基础词库与用户词库相互独立；用户词自动按当前简繁模式展示，无需重复学习。低频专业词汇仅在完整精确输入时出现。无法解析为合法音节的字母以红色标出，不改动原始输入。支持在“高级”页导入其他输入法导出的词频数据，详见[输入频次导入](CONFIGURATION.md#输入频次导入)。
- **快捷输入**：`ufh` 输入常用符号，`uxh` 输入数字序号，`usx` 输入数学符号，`urq` / `usj` 输入当前日期与时间等；`i123.45` 或 `v123.45` 转换中文数字及金额大写，数字键可继续追加数字，按候选旁的 `a/b/c/d` 选词。双拼模式下通过 Shift+U/I/V 进入，详见[快捷输入说明](QUICK_INPUT.md)。
- **中文标点**：中文标点半角模式下，紧跟数字后的句号自动输出为小数点；支持自定义原样输出为半角的符号，或一键切换 Markdown 预设与标准中文标点。默认启用 Markdown 预设（保留 ``-#*+_=`~[]<>|@`` 为半角），逗号、句号、圆括号与引号仍输出中文标点，反斜杠输出顿号 `、`。
- **自定义短语**：通过字母缩写触发预设文本，按 Tab 原样上屏；支持多行内容、自定义排序、重码优先级及与 Windows 版兼容的 JSON 导入导出。新建时填写缩写与内容后点击“添加短语”，修改已有条目时点击“保存修改”或“取消编辑”。
- **设置**：采用左侧分类导航的设置窗口，修改确认后立即保存生效；支持直接按键录制快捷键与字体名称自动补全。日志默认关闭。 “按键”页集中翻页、选词和补全选项，可开启 `[` / `]` 取当前词的首字／末字。
- **完全本地**：全程离线运行，无需联网或 GPU。引擎启动期间的按键会自动暂存并在就绪后照常转换；语言模型尚未加载完成或不可用时，基础词库候选仍可正常输入，仅跳过模型重排。

## 2.9.0 的改进

- **候选可以竖排。** 在“外观 → 候选排列”选择“竖排”，每行显示一个词，上下键逐词选择。三种排列都保留翻页键和底部的 Tab 补全栏。
- **已学词语可以带走，也可以单独删除。** 在“高级”导出两个字及以上的已学词语、拼音和使用次数，换机后导入 CSV。按汉字或拼音前缀可以找到并删除某个读音的学习记录。批量导入只累计频次，不触发两小时内重复选词的临时置顶。
- **长句选词和补全更准。** 本地字符模型在训练时向 Qwen3.5-9B-Base 学习整句和续写偏好，部署体积保持不变。七组决策树重新训练，其中新增的长句纠错决策树会结合读音与整句得分、改动字数和词频判断是否采纳改写。
- **补足读音和日常表达。** 新词库增加常用词和缺失的读音。日常对话里高频的同音词，在和书面词竞争时更容易保住首选。

## 下载与安装
- **下载**：前往 [Releases](https://github.com/shenmin/cassotis-ime-mac/releases) 页面下载 `cassotis-ime-macos-<版本号>-arm64-installer-signed.dmg`（约 340 MB，内置简繁基础词库与语言模型）。正式发布镜像均由 Sunisoft Limited 的 Developer ID 签名并通过 Apple 公证。
- **系统要求**：搭载 Apple 芯片的 Mac，macOS 14 及以上。无需终端命令、编译器、Python、联网或 GPU。
- **安装**：打开磁盘映像，双击“言泉输入法安装器”并点击“安装”；系统提示启用输入源时点击“允许”。显示“安装完成”后，从菜单栏输入法菜单选择“言泉输入法”，输入 `nihao` 并按空格即可上屏“你好”。若输入源尚未启用，可点击“重试启用”，或点击“打开键盘设置”手动添加。
- **macOS 27**：系统可能直接打开键盘设置而不弹出授权确认。请在“文字输入 → 编辑 → + → 中文（简体）”中手动添加“言泉输入法”，返回安装器后会自动核实启用状态。
- **升级**：直接运行新版本安装器覆盖安装即可，原有设置与学习记录会自动保留；安装过程显示实时进度，出错时可查看日志或重试。
- **卸载**：先在“系统设置”中移除输入源，再使用安装器内置的卸载功能；用户设置与学习记录默认保留。

## 架构
- `src/macos`：InputMethodKit 输入控制器，以及 AppKit 候选窗、状态气泡与设置窗口（Objective-C++）。
- `src/service`、`src/ipc`：独立引擎进程服务与 Unix socket 通信协议。
- `src/engine`、`src/dictionary`：拼音解析、候选生成、排序与用户学习逻辑，移植自 Windows 版。
- `src/host`：语言模型推理宿主；`src/host/native` 为对接 ONNX Runtime 的 C++ 桥接层与自定义注意力算子。
- `src/common`：配置读写、公共类型与平台适配。
- `src/installer`：图形界面安装器。
- `tools/dictionary`、`tools/control`：词库构建导入工具与输入源控制工具。
- `data`：语言模型分片（`data/models/char_lm`）、模型校验值与词库输入哈希。
- `scripts`、`resources`：构建、安装与打包脚本；应用图标与包内资源。
- `third_party`：ONNX Runtime 头文件与版本配置，以及随附第三方组件的许可证与声明。

进程分工、IPC 协议与故障恢复机制见[架构文档](docs/ARCHITECTURE.md)。

## 运行时文件
- `Cassotis.app/Contents/MacOS/Cassotis`：输入法前端进程，由 macOS 输入法子系统按需启动。
- `Cassotis.app/Contents/MacOS/cassotis-engine`：后端引擎进程，负责加载词库与语言模型；由前端以 `--serve` 参数拉起，通过私有 Unix socket 通信。
- `Cassotis.app/Contents/Frameworks/libcassotis_ort.dylib` 与 `libonnxruntime.1.20.1.dylib`：语言模型桥接库与 ONNX Runtime 运行库，仅由引擎进程加载。
- `Cassotis.app/Contents/Resources/models/char_lm`：语言模型文件、字符词表、拼音读音表与运行清单。
- `Cassotis.app/Contents/Resources/dictionaries`：简体与繁体基础词库（`dict_sc.db`、`dict_tc.db`）。

拼音转换依赖 `cassotis-engine` 进程。当 IPC 请求失败或超时时，前端会先上屏当前可见的组合串，将本次按键交还宿主应用，并自动重启引擎进程。若模型文件缺失，输入法仍可正常查词输入，仅跳过语言模型重排。

## 构建与安装（快速开始）
前置条件：搭载 Apple 芯片的 Mac、Free Pascal 3.2.2、Xcode 命令行工具及 Python 3.11 或更高版本（不依赖 Lazarus/LCL）。准备好 [Cassotis Lexicon v2.9.0](https://github.com/shenmin/cassotis-lexicon) 的生成文件，并将 `CASSOTIS_LEXICON_ROOT` 指向该目录（下方 `/path/to/...` 为占位路径）：

```sh
./scripts/check_environment.sh
export CASSOTIS_LEXICON_ROOT="/path/to/cassotis-lexicon"
./build_all.sh
./install.sh
```

构建产物位于 `build/arm64/Cassotis.app`，并安装至当前用户的 `~/Library/Input Methods/Cassotis.app`（请勿使用 `sudo` 执行脚本）。随后在“系统设置 → 键盘 → 文字输入”中添加言泉输入法，并从菜单栏切换选用；若输入源列表未及时刷新，可注销后重新登录。

`build_all.sh` 会依次构建语言模型桥接库、引擎、简繁基础词库、前端与安装器，并在校验 SHA-256 后将 `data/models/char_lm` 下的编号分片合并为应用包内的 `char_lm.onnx`。首次构建会自动下载官方 ONNX Runtime 1.20.1 arm64 发行包并校验固定哈希。`./rebuild_all.sh` 用于清理后完整重建，`./uninstall.sh` 用于卸载输入法（保留学习记录），`./scripts/package.sh` 用于生成安装包磁盘映像。构建参数、打包与代码签名详见 [BUILD.md](BUILD.md)。

## 词库流程
基础词库采用 [Cassotis Lexicon](https://github.com/shenmin/cassotis-lexicon) schema 24 格式的 SQLite 数据库，由其 `data/generated/` 目录下的 30 个生成文件导入构建：
- 基础与单字词表：`dict_unihan_sc.txt`、`dict_unihan_tc.txt`、`dict_clean_sc.txt`、`dict_clean_tc.txt`（格式为 `pinyin<TAB>text<TAB>weight`）；
- 语料统计表：词间转移先验、补全先验、通用语料与日常对话词频，以及离线预计算的短词首选提升表。

构建时按 [data/lexicon-inputs.json](data/lexicon-inputs.json) 逐一核对输入文件哈希，生成 `dict_sc.db` 与 `dict_tc.db` 并打包入应用。v2.9.0 词库共收录简体 269,924 条、繁体 272,681 条读音记录（含单字）。用户词库、引擎配置与学习数据存放在 `~/Library/Application Support/CassotisIME/`，更新或替换应用不会覆盖。

## 模型与排序
macOS 版的语言模型与紧凑排序组件与 Cassotis IME Windows v2.9.0 完全对齐：模型文件逐字节一致，编译进引擎的模型参数也完全一致。

### 字符级语言模型
- **统一本地语言模型**：内置自研约 1.5 亿参数的字符级自回归语言模型（11 层、1024 维隐藏层、12,017 字词表、8 位静态量化）。长句整句打分与同音纠错、短词消歧、带上下文单字排序、词库外短语组句、中英候选权衡、一键补全重排以及长句 Tab 续写均由该模型统一承担；早期版本按阶段拆分的多套独立模型已全部移除。
- **训练语料与口语适配**：模型在独立的通用中文文本与小说语料上联合训练普通语言建模与拼音条件纠错能力。自 v2.7.0 起进一步融入日常口语：从公开对话语料 LCCC 中筛选最贴近日常聊天的十分之一继续训练，再与原模型按 1:1 平均权重，在提升口语表现的同时保持小说与通用文本上的准确率。所有基准测试用例均严格排除在训练数据之外。 2.9.0 使用 Qwen3.5-9B-Base 做整句蒸馏，前四个字的位置锚定原模型，最终权重与原模型等权平均。本机只运行所得的字符模型。
- **推理结果确定性**：模型采用固定激活范围的静态量化，并由自定义注意力算子执行推理；Apple 芯片上的 ARM NEON 内核保持与 Windows 端一致的求和顺序。同一文本无论如何分批或此前计算过哪些缓存，输出得分均严格一致，确保逐键输入长句与一次性输入完整拼音得到相同的候选结果。

### 排序决策与统计先验
- **轻量梯度提升决策模型（GBDT）**：7 个小型 GBDT 模型综合语言模型得分与词库特征作出排序决策，分别对应长句优选、长句纠错改写、无上文短词排序、有上文短词排序及其细分判别、一键补全触发和长句 Tab 续写。各模型基于 Windows 引擎在独立语料上的运行特征训练，随语言模型同步重训，并以相同参数编译进引擎。
- **紧凑结构排序器**：3 个轻量结构排序模块负责长句路径搜索中的剪枝保留与完整候选池初排。
- **词库统计先验**：词库统计表补充词间转移、补全先验、随词库预计算的短词首选提升表，以及通用语料词频与日常对话词频等先验特征。

### 各场景排序机制
繁体输入时，引擎先按对应简体字交由语言模型评分，并将模型生成的补全结果转换为台湾常用繁体字形；前台选词与后台补全共用同一模型。

- **长句**：受词库约束的路径搜索生成完整候选，其中 2 个结构排序器负责搜索剪枝，第 3 个对完整候选池排序；语言模型为头部候选打分后，由长句 GBDT 选出前两名结果。在简繁体、全拼及双拼模式下，模型还会结合输入音节与光标前最多 48 个字，最多执行两轮同音纠错与联合评分，修正少量同音错字；用户词与完整拼音精确匹配的词库词保持不变。
- **短词与单字**：同音精确候选默认保持词库顺序，仅在语言模型结合光标前上文给出明确优势时由短词 GBDT 调整顺序。无上文时同时参考通用语料词频，并对日常对话中明显高频的首选词加以保护（如 `zhezhou` → `这周`）；仅凭词库排序的场景则由预计算的短词提升表校准。单音节单字在有上文时由语言模型按语境排序，无上文时按现代文本字频排序。
- **词库外短语**：输入三至五个音节且未命中基础词库或用户词库时，引擎先按不同切分方式组合词库词条生成整句草稿，由语言模型结合光标前上文评估分句通顺度并选出最佳草稿，再对照输入音节修正同音字。支持简繁体、全拼与双拼；开启模糊音或输入含分隔符 `'` 时不启用。用户手动选择的非首选短语会记为用户词。
- **英文字母**：当输入字母同时可解析为中文拼音时，语言模型结合上文在单次调用中对比英文原词与当前页前几个中文候选，仅在英文优势明确时将其排在前面。
- **一键补全**：词库精确补全与强转移补全即时显示；语言模型随后在后台对更大范围的词库词重排，仅在优势明确时替换已显示的补全。
- **长句 Tab 续写**：语言模型预测后续字符，并统一评估补完当前词与续写后续短语的候选方案，由 Tab 续写 GBDT 择优提示或在把握不足时隐藏。

### 本地推理机制
- 全部推理均在本机 CPU 上通过随附的 ONNX Runtime 完成，不联网、不使用 GPU。
- 模型仅由引擎进程在后台异步加载，常规候选、选词、上屏及词库补全无需等待加载完成。
- 单次语言模型调用的上限为 100 ms。长句 Tab 最多等待后台续写 120 ms，已有候选照常先显示。
- 推理线程数优先按高性能核心数确定，限制在 4 至 8 个；系统未提供核心分级信息时回退至物理或逻辑 CPU 数量。
- 仅读取光标前最多 1,024 个 UTF-16 代码单元作为上下文，绝不读取密码框内容。

## 配置
可从菜单栏输入法菜单打开“设置…”，或按 Ctrl+Shift+F10 呼出；确认后的修改立即保存并生效。

主要配置项包括：
- 简繁词库与拼音方案（全拼或 7 种双拼之一）
- 逐项模糊音开关
- 每页候选数（3 至 9）、翻页键、补全键及 5 个可独立启用的功能快捷键
- 中英文切换键：Shift 或 Caps Lock（默认 Shift）
- 按应用独立记忆中英文状态（默认开启）
- 中文模式下的英文识别（默认开启）
- 数字后的句号自动转为小数点（默认开启）
- 中文标点模式下保持半角输出的符号（默认 Markdown 预设）
- 候选字体、字号、配色，以及横排、翻页展开三行或竖排
- 候选窗固定在输入起点或跟随光标（默认固定在起点）
- 用 `;` 和 `'` 选择第二、第三个候选（默认关闭）
- `[` / `]` 以词定字，选择当前候选的首字或末字（默认关闭；与方括号翻页互斥）
- 光标旁的中英文状态提示气泡（默认开启）
- 自定义短语（添加／保存修改、排序及 JSON 导入／导出）
- 高级页：导入其他输入法的输入频次
- 高级页：运行日志开关（默认关闭；日志目录为 `~/Library/Logs/CassotisIME/`）
- 高级页：排序上文调试显示（默认关闭，独立于运行日志）

界面显示偏好保存在 `org.cassotis.inputmethod.Cassotis` 的 UserDefaults 中；引擎配置与学习数据位于 `~/Library/Application Support/CassotisIME/`。完整按键与选项说明见[使用与设置](CONFIGURATION.md)。

## 版本历史
以下梳理 macOS 版的关键版本演进与模型架构迭代。括号内标注对标的 Cassotis IME Windows 版版本号；完整变更见[更新日志](CHANGELOG.md)（英文）及 [Releases](https://github.com/shenmin/cassotis-ime-mac/releases) 发布说明。

**v0.1.0（build 1，Windows v1.27.0）：首个公开发布版本。** 原生 InputMethodKit / AppKit 输入法前端搭配独立 Free Pascal 引擎进程、本地 ONNX 推理与简繁词库；支持全拼、简拼、6 种双拼、模糊音、本地自学习与 Tab 补全；提供双行候选窗、8 套配色、光标旁状态气泡、即时生效的设置窗口及保留用户数据的签名安装器。

**v0.2.0（build 2，Windows v1.29.0）：跨平台数值与排序对齐。** 引入结合上下文的短词重排、长句书面短语恢复、可选三行候选展开与跨行鼠标选词，以及仅在精确输入时展示的专业词汇；对齐最小整数边界比较与浮点中间精度语义，使 Apple 芯片下 Free Pascal 编译的引擎与 Windows 版 Delphi 引擎输出一致的候选路径和分数。

**v1.0.0（build 3，Windows v1.31.0）：引入共享字符语言模型。** 以字符级语言模型取代原有的 RBT3 短上下文模型，统一承担长句排序、上下文短词消歧、混合简拼与 Tab 续写；支持短词补全后台重排，以及长句下当前词补全、后续短语与预测字符的综合比较。

**v2.0.0（build 4，Windows v2.2.0）：单模型架构整合。** 将 v1.0.0 中按输入阶段拆分的 11 个神经网络图整合为单一字符语言模型与 7 个轻量排序单元，全面移除旧模型图、辅助索引与旧宿主代码。新增三至五音节词库外短语组句与同音纠错，并加入中文模式英文识别、U/I/V 快捷输入、数字后自动小数点、Markdown 标点预设、按应用记忆中英文状态及自定义短语。

**v2.1.0（build 5，Windows v2.4.0）：繁体模式接入语言模型。** 繁体候选与上下文映射为对应简体交由模型评分，同时在候选展示、翻页、上屏及 Tab 补全中保持台湾常用繁体字形；新增外部输入法词频导入与排序上文调试显示。

**v2.5.0（build 6，Windows v2.5.0）：引入通用语料词频与版本号对齐。** 短词排序引入通用语料词频特征，提升无上下文时的常用词首选率，并将词间转移改为按查询按需读取；支持单音节全量单字翻页、Caps Lock 切换中英文，以及按高性能核心数配置模型线程。自本版本起，macOS 版与 Windows 版统一版本号。

**v2.6.0（build 7，Windows v2.6.0）：联合评分纠错与上下文短词专有策略。** 拼音条件纠错与语言模型联合评分决定长句改写，支持整词同音替换；拆分独立的带上下文短词决策模型（GBDT），无上下文单字改按现代字频排序，并在完整音节单字后补充双音节切分前缀字（如输入 `shua` 时可选 `shu` 对应的字）。

**v2.7.0（build 8，Windows v2.7.0）：日常对话适配与全模式覆盖。** 语言模型增量融合日常对话语料并重训全部 6 个 GBDT 决策模型，无上下文时保护日常口语高频首选；词库外短语组句与长句纠错扩展至繁体及双拼模式，新增带上下文单字模型排序、长句二轮纠错复查与智能 ABC 双拼。

**v2.9.0（build 10）。** 蒸馏升级本地模型，增加长句纠错决策树、竖排候选及已学词语的导出与管理。
