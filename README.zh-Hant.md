Cassotis IME macOS 版（言泉輸入法 macOS 版）是一款面向 Apple 晶片 Mac 的實驗性中文拼音輸入法。原生 InputMethodKit / AppKit 前端透過跨處理程序通訊連接 Free Pascal 撰寫的獨立引擎處理程序；核心引擎移植自 [Cassotis IME Windows 版](https://github.com/shenmin/cassotis-ime)，基礎詞庫由 [Cassotis Lexicon](https://github.com/shenmin/cassotis-lexicon) 建置。候選排序由本專案訓練的字元級語言模型驅動，全程在本機 CPU 上執行。無廣告、不綑綁其他軟體，也不上傳任何輸入內容，詞庫、設定與使用者學習資料均儲存在本機。

macOS 2.7.0（build 8）對標 Cassotis IME 與 Cassotis Lexicon v2.7.0，支援搭載 Apple 晶片、執行 macOS 14 及以上的裝置。可下載 [v2.7.0 安裝套件](https://github.com/shenmin/cassotis-ime-mac/releases/download/v2.7.0/cassotis-ime-macos-2.7.0-arm64-installer-signed.dmg)或查看[更新說明](https://github.com/shenmin/cassotis-ime-mac/releases/tag/v2.7.0)；產品概覽請見[官網](https://www.yanquan.org/mac)，已驗證環境與已知限制請見 [COMPATIBILITY.md](COMPATIBILITY.md)，歷次版本演進請見下文[版本歷史](#版本歷史)。

專案目前重點：
- 與 Windows 版保持版本同步，並在同一套基準測試集上核驗排序結果；
- 基於 macOS 公開的 InputMethodKit 與 AppKit 介面實作，不需要「輔助使用」或「輸入監控」權限；
- 提供經 Apple 簽章與公證的離線安裝套件，無需連網或 GPU。

## 名稱來源
英文名 **Cassotis** 源自古希臘 Delphi 神廟內的聖泉。相傳女祭司皮媞亞（Pythia）在傳達神諭前會飲用泉水以獲得靈感；聖泉由此象徵預言與話語的源頭，也呼應了核心引擎源自 Delphi 語言的背景。

中文名 **言泉** 既對應 Cassotis「預言之泉」的本義，也取「言如泉湧」之意，寓意流暢自然的輸入體驗。

## 主要功能
- **原生輸入法**：基於 InputMethodKit 輸入源與 AppKit 實作，候選視窗不會搶占目前應用程式的輸入焦點。支援在原生文字欄位、WebKit、Chrome、Electron 及終端機中進行組字、分段選詞與送出；密碼欄位維持系統預設的安全輸入機制。
- **候選視窗**：預設採用雙行配置：首行單行顯示最多 9 個編號候選詞，次行為常駐 Tab 補全區（右側顯示圖示與版本號）。翻頁時可展開為三行候選，數字鍵與空白鍵選擇目前行候選，滑鼠可直接點選任意可見行。單音節輸入支援翻頁瀏覽全部同音單字（含候選超過 256 個的讀音）；點按使用者詞右側的紅色 `×` 即可刪除該詞。內建 8 套配色，字級支援 12 至 32 點（預設 14 點）並可即時預覽。候選視窗預設固定在本次輸入起點，可在「外觀」頁改為跟隨游標；支援開啟 `;` 和 `'` 選擇第 2、3 個候選（預設關閉，雙拼模式下作韻母鍵時優先）。在候選視窗上按右鍵可開啟狀態切換、設定與關於選單，且不中斷目前輸入的拼音。
- **中英文切換**：單擊 Shift 切換中英文，游標旁會短暫彈出帶圖示的「中/英」狀態氣泡（可在「外觀」頁關閉）；切換至言泉輸入法或在英文模式下聚焦輸入框時也會提示。支援改用 Caps Lock 切換（目前不區分短按與長按，啟用前請參閱[設定說明](CONFIGURATION.md)），預設依應用程式獨立記住中英文狀態。按住修飾鍵期間若觸發其他按鍵或滑鼠點擊，不會誤觸切換；前端僅比對系統範圍的事件計數，不讀取其他按鍵內容。
- **英文辨識**：在中文全拼半形模式下，常見英文單字與專有名詞（如 `pro`、`markdown`、`Effie`）、含大寫字母的輸入及曾以英文送出的詞條，會保留大小寫排在編號候選之前。若輸入不構成完整中文拼音，預設選中英文並可按空白鍵直接送出；若同時存在中文讀法（如 `bug`、`mac`），則由語言模型結合上文判斷優先順序。可用方向鍵或滑鼠切換英文與中文候選，中文候選編號維持不變；選擇英文送出會記錄偏好，但不寫入使用者詞庫。預設開啟，可在設定中關閉；雙拼模式仍按中文規則處理。
- **一鍵補全**：Tab 補全區每次僅顯示一條高把握度的續寫建議，按設定的補全鍵即可送出。使用者詞、基礎詞庫精確匹配詞及經離線篩選的強轉移搭配會即時顯示，隨後由語言模型結合游標前上文在背景重排。長句輸入時可補完目前詞語或續寫後續短語，把握不足時不提示。模型預測結果以主題強調色顯示，已輸入拼音的直接拼接則使用一般文字顏色。古詩詞支援從開頭幾個音節補全，完整輸入上句後還可提示下句（如「春眠不覺曉，處處聞啼鳥」）。
- **長句**：基於詞庫約束的路徑搜尋產生整句候選（如 `womenjintian` → `我們今天`），同時保留前綴候選供分段送出。語言模型在整句候選中擇優，並在簡繁體、全拼及雙拼模式下結合輸入拼音與游標前上文，自動修正整句中的少量同音錯字。
- **短詞**：多個同音精確候選競爭時，由語言模型結合上文與通用語料詞頻綜合排序；無上文時兼顧通用詞頻與日常對話高頻詞保護，避免生僻詞或書面詞擠占常用首選。有上文時，單音節同音字同樣由語言模型依語境排序。
- **短語**：簡繁體模式下，輸入詞庫未收錄的三至五音節短語（如 `jiuguize` → `旧规则`）時，引擎會先組合詞庫詞條產生整句草稿，由語言模型結合游標前上文選出最通順的方案並修正同音字；若多個方案得分接近，首選後最多再附帶兩個備選短語。
- **拼音方案**：支援全拼及 7 種雙拼方案（微軟雙拼、小鶴雙拼、自然碼雙拼、搜狗雙拼、紫光雙拼、拼音加加和智慧 ABC），共用候選排序與使用者學習資料；支援逐項設定模糊音、首字母簡拼（如 `jt` → `今天`），以及以 `v` 輸入 `ü`（`lv`、`nv`，相容 `lue`/`nue` 和 `jv`/`qv`/`xv`）。
- **詞庫與學習**：簡體基礎詞庫、繁體基礎詞庫與使用者詞庫相互獨立；使用者詞自動依目前簡繁模式顯示，無需重新學習。低頻專業詞彙僅在完整精確輸入時出現。無法解析為合法音節的字母以紅色標示，不改動原始輸入。支援在「進階」頁匯入其他輸入法匯出的詞頻資料，詳見[輸入頻次匯入](CONFIGURATION.md#输入频次导入)。
- **快捷輸入**：`ufh` 輸入常用符號，`uxh` 輸入數字序號，`usx` 輸入數學符號，`urq` / `usj` 輸入目前日期與時間等；`i123.45` 或 `v123.45` 轉換中文數字及金額大寫，數字鍵可繼續輸入數字，按候選旁的 `a/b/c/d` 選詞。雙拼模式下透過 Shift+U/I/V 進入，詳見[快捷輸入說明](QUICK_INPUT.md)。
- **中文標點**：中文標點半形模式下，緊接數字後的句號自動輸出為小數點；支援自訂原樣輸出為半形的符號，或一鍵切換 Markdown 預設組合與標準中文標點。預設啟用 Markdown 組合（保留 ``-#*+_=`~[]<>|@`` 為半形），逗號、句號、圓括號與引號仍輸出中文標點，反斜線輸出頓號 `、`。
- **自訂短語**：透過英文字母縮寫觸發預設文字，按 Tab 原樣送出；支援多行內容、自訂排序、重碼優先順序及與 Windows 版相容的 JSON 匯入匯出。新增時填寫縮寫與內容後點擊「添加短语」，編輯已有條目時使用「保存修改」或「取消编辑」。
- **設定**：採用左側分類導覽的設定視窗，修改確認後立即儲存生效；支援直接按鍵錄製快捷鍵與字型名稱自動補全。記錄檔預設關閉。
- **完全本機**：全程離線執行，無需連網或 GPU。引擎啟動期間的按鍵會自動暫存並在就緒後照常轉換；語言模型尚未載入完成或無法使用時，基礎詞庫候選仍可正常輸入，僅跳過模型重排。

## 2.7.0 的改進

- **新增智慧 ABC 雙拼**：全部 7 種雙拼方案及繁體模式均完整支援短詞優選、詞庫外短語組句、長句同音修正與 Tab 續寫。
- **單字結合上文排序**：有上文時，同音單字綜合語言模型得分與現代字頻排序；無上文時維持常用字順序，使用者選過的字詞繼續優先。
- **最佳化長句與短語品質**：長句修正支援首輪修改後的二輪複查；以「沒」結尾的短語按疑問句評分，並減少罕見補全及偏書面詞對日常表達的干擾。
- **增強選詞與快捷選單**：可在「快捷鍵」頁開啟 `;` 選第二項、`'` 選第三項（預設關閉，雙拼韻母輸入優先）；在候選視窗按右鍵可切換狀態或開啟設定與關於。
- **候選視窗定位更穩定**：預設固定在本次輸入起點，可在「外觀」頁改為跟隨游標，修改即時生效。
- **升級模型與詞庫**：同步至 v2.7.0 語言模型權重、排序參數與詞庫，加入日常對話詞頻保護，修正臺灣用字與多音字讀音；安裝套件仍僅內建單一神經網路模型。

## 下載與安裝
- **下載**：前往 [Releases](https://github.com/shenmin/cassotis-ime-mac/releases) 頁面下載 `cassotis-ime-macos-<版本號>-arm64-installer-signed.dmg`（約 340 MB，內建簡繁基礎詞庫與語言模型）。正式發布映像均由 Sunisoft Limited 的 Developer ID 簽章並通過 Apple 公證。
- **系統需求**：搭載 Apple 晶片的 Mac，macOS 14 及以上。無需終端機指令、編譯器、Python、連網或 GPU。
- **安裝**：開啟磁碟映像，按兩下「言泉输入法安装器」並點按「安装」；系統提示啟用輸入源時請點按「允許」。顯示「安装完成」後，從選單列輸入選單選擇「言泉输入法」，輸入 `nihao` 並按空白鍵即可打出「你好」。若輸入源尚未啟用，可點按「重试启用」，或點按「打开键盘设置」手動加入。
- **macOS 27**：系統可能直接開啟鍵盤設定而不彈出授權確認。請在「文字輸入 → 編輯 → + → 中文（簡體）」中手動加入「言泉输入法」，返回安裝程式後會自動核實啟用狀態。
- **升級**：直接執行新版本安裝程式覆蓋安裝即可，原有設定與學習紀錄會自動保留；安裝過程顯示即時進度，出錯時可查看記錄檔或重試。
- **解除安裝**：先在「系統設定」中移除輸入源，再使用安裝程式內建的解除安裝功能；使用者設定與學習紀錄預設保留。

## 架構
- `src/macos`：InputMethodKit 輸入控制器，以及 AppKit 候選視窗、狀態氣泡與設定視窗（Objective-C++）。
- `src/service`、`src/ipc`：獨立引擎處理程序服務與 Unix socket 通訊協定。
- `src/engine`、`src/dictionary`：拼音解析、候選產生、排序與使用者學習邏輯，移植自 Windows 版。
- `src/host`：語言模型推論宿主；`src/host/native` 為銜接 ONNX Runtime 的 C++ 橋接層與自訂注意力運算子。
- `src/common`：設定讀寫、共用型別與平台適配。
- `src/installer`：圖形介面安裝程式。
- `tools/dictionary`、`tools/control`：詞庫建置匯入工具與輸入源控制工具。
- `data`：語言模型分片（`data/models/char_lm`）、模型校驗值與詞庫輸入雜湊值。
- `scripts`、`resources`：建置、安裝與封裝腳本；應用程式圖示與套件資源。
- `third_party`：ONNX Runtime 標頭檔與版本設定，以及隨附第三方元件的授權條款與聲明。

處理程序分工、通訊協定與故障復原機制請見[架構文件](docs/ARCHITECTURE.md)。

## 執行階段檔案
- `Cassotis.app/Contents/MacOS/Cassotis`：輸入法前端處理程序，由 macOS 為輸入源按需啟動。
- `Cassotis.app/Contents/MacOS/cassotis-engine`：後端引擎處理程序，負責載入詞庫與語言模型；由前端以 `--serve` 參數啟動，透過私有 Unix socket 通訊。
- `Cassotis.app/Contents/Frameworks/libcassotis_ort.dylib` 與 `libonnxruntime.1.20.1.dylib`：語言模型橋接庫與 ONNX Runtime 執行階段程式庫，僅由引擎處理程序載入。
- `Cassotis.app/Contents/Resources/models/char_lm`：語言模型檔案、字元詞彙表、拼音讀音表與執行清單。
- `Cassotis.app/Contents/Resources/dictionaries`：簡體與繁體基礎詞庫（`dict_sc.db`、`dict_tc.db`）。

拼音轉換依賴 `cassotis-engine` 處理程序。當 IPC 請求失敗或逾時時，前端會先送出目前可見的組字內容，將本次按鍵交還宿主應用程式，並自動重新啟動引擎處理程序。若模型檔案缺失，輸入法仍可正常查詞輸入，僅跳過語言模型重排。

## 建置與安裝（快速開始）
前置條件：搭載 Apple 晶片的 Mac、Free Pascal 3.2.2、Xcode 命令列工具及 Python 3.11 或更高版本（不依賴 Lazarus/LCL）。準備好 [Cassotis Lexicon v2.7.0](https://github.com/shenmin/cassotis-lexicon) 的產生檔案，並將 `CASSOTIS_LEXICON_ROOT` 指向該目錄（下方 `/path/to/...` 為佔位路徑）：

```sh
./scripts/check_environment.sh
export CASSOTIS_LEXICON_ROOT="/path/to/cassotis-lexicon"
./build_all.sh
./install.sh
```

建置產物位於 `build/arm64/Cassotis.app`，並安裝至目前使用者的 `~/Library/Input Methods/Cassotis.app`（請勿以 `sudo` 執行腳本）。隨後在「系統設定 → 鍵盤 → 文字輸入」中加入言泉輸入法，並從輸入選單切換選用；若輸入源清單未及時更新，可登出後重新登入。

`build_all.sh` 會依序建置語言模型橋接庫、引擎、簡繁基礎詞庫、前端與安裝程式，並在核對 SHA-256 後將 `data/models/char_lm` 下的編號分片合併為應用程式套件內的 `char_lm.onnx`。首次建置會自動下載官方 ONNX Runtime 1.20.1 arm64 發行套件並校驗固定雜湊值。`./rebuild_all.sh` 用於清理後完整重建，`./uninstall.sh` 用於解除安裝輸入法（保留學習紀錄），`./scripts/package.sh` 用於產生安裝磁碟映像。建置選項、封裝與程式碼簽章詳見 [BUILD.md](BUILD.md)。

## 詞庫流程
基礎詞庫採用 [Cassotis Lexicon](https://github.com/shenmin/cassotis-lexicon) schema 24 格式的 SQLite 資料庫，由其 `data/generated/` 目錄下的 30 個產生檔案匯入建置：
- 基礎與單字詞表：`dict_unihan_sc.txt`、`dict_unihan_tc.txt`、`dict_clean_sc.txt`、`dict_clean_tc.txt`（格式為 `pinyin<TAB>text<TAB>weight`）；
- 語料統計表：詞間轉移先驗、補全先驗、通用語料與日常對話詞頻，以及離線預先計算的短詞首選提升表。

建置時依 [data/lexicon-inputs.json](data/lexicon-inputs.json) 逐一核對輸入檔案雜湊值，產生 `dict_sc.db` 與 `dict_tc.db` 並封裝進應用程式套件。v2.7.0 詞庫共收錄簡體 264,167 筆、繁體 267,265 筆讀音紀錄（含單字）。使用者詞庫、引擎設定與學習資料存放在 `~/Library/Application Support/CassotisIME/`，更新或替換應用程式不會覆蓋。

## 模型與排序
macOS 版的語言模型與緊湊排序元件與 Cassotis IME Windows v2.7.0 完全對齊：模型檔案逐位元組一致，編譯進引擎的模型參數也完全一致。

### 字元級語言模型
- **統一本機語言模型**：內建本專案訓練的約 1.5 億參數字元級自迴歸語言模型（11 層、1024 維隱藏層、12,017 個字元的詞彙表、8 位元靜態量化）。長句整句評分與同音修正、短詞消歧、帶上下文單字排序、詞庫外短語組句、中英候選權衡、一鍵補全重排以及長句 Tab 續寫均由該模型統一承擔；早期版本按階段拆分的多套獨立模型已全部移除。
- **訓練語料與口語適配**：模型在獨立的通用中文文本與小說語料上聯合訓練一般語言建模與拼音條件修正能力。自 v2.7.0 起進一步融入日常口語：從公開對話語料 LCCC 中篩選最貼近日常聊天的十分之一繼續訓練，再與原模型按 1:1 平均權重，在提升口語表現的同時維持小說與通用文本上的準確率。所有基準測試案例均嚴格排除在訓練資料之外。
- **推論結果確定性**：模型採用固定活化範圍的靜態量化，並由自訂注意力運算子執行推論；Apple 晶片上的 ARM NEON 核心維持與 Windows 端一致的加總順序。同一段文字無論如何分批或先前計算過哪些快取，輸出得分均嚴格一致，確保逐鍵輸入長句與一次輸入完整拼音得到相同的候選結果。

### 排序決策與統計先驗
- **輕量梯度提升決策模型（GBDT）**：6 個小型 GBDT 模型綜合語言模型得分與詞庫特徵作出排序決策，分別對應長句優選、無上文短詞排序、有上文短詞排序及其細分判別、一鍵補全觸發和長句 Tab 續寫。各模型基於 Windows 引擎在獨立語料上的執行特徵訓練，隨語言模型同步重新訓練，並以相同參數編譯進引擎。
- **緊湊結構排序器**：3 個精簡結構排序模組負責長句路徑搜尋中的剪枝保留與完整候選池初排。
- **詞庫統計先驗**：詞庫統計表補充詞間轉移、補全先驗、隨詞庫預先計算的短詞首選提升表，以及通用語料詞頻與日常對話詞頻等先驗特徵。

### 各場景排序機制
繁體輸入時，引擎先依對應簡體字交由語言模型評分，並將模型產生的補全結果轉換為臺灣常用繁體字形（臺灣用字）；前景選詞與背景補全共用同一模型。

- **長句**：受詞庫約束的路徑搜尋產生完整候選，其中 2 個結構排序器負責搜尋剪枝，第 3 個對完整候選池排序；語言模型為前段候選評分後，由長句 GBDT 選出前兩名結果。在簡繁體、全拼及雙拼模式下，模型還會結合輸入音節與游標前最多 48 個字元，最多執行兩輪同音修正與聯合評分，改正少量同音錯字；使用者詞與完整拼音精確匹配的詞庫詞維持不變。
- **短詞與單字**：同音精確候選預設維持詞庫順序，僅在語言模型結合游標前上文給出明確優勢時由短詞 GBDT 調整順序。無上文時同時參考通用語料詞頻，並對日常對話中明顯高頻的首選詞加以保護（如 `zhezhou` → `这周`）；僅憑詞庫排序的場景則由預先計算的短詞提升表校準。單音節單字在有上文時由語言模型依語境排序，無上文時依現代文本字頻排序。
- **詞庫外短語**：輸入三至五個音節且未命中基礎詞庫或使用者詞庫時，引擎先依不同切分方式組合詞庫詞條產生整句草稿，由語言模型結合游標前上文評估分句通順度並選出最佳草稿，再對照輸入音節修正同音字。支援簡繁體、全拼與雙拼；開啟模糊音或輸入含分隔符 `'` 時不啟用。使用者手動選擇的非首選短語會記為使用者詞。
- **英文字母**：當輸入字母同時可解析為中文拼音時，語言模型結合上文在單次呼叫中對比英文原詞與目前頁前幾個中文候選，僅在英文優勢明確時將其排在前面。
- **一鍵補全**：詞庫精確補全與強轉移補全即時顯示；語言模型隨後在背景對更大範圍的詞庫詞重排，僅在優勢明確時替換已顯示的補全。
- **長句 Tab 續寫**：語言模型預測後續字元，並統一評估補完目前詞語與續寫後續短語的候選方案，由 Tab 續寫 GBDT 擇優提示或在把握不足時隱藏。

### 本機推論機制
- 全部推論均在本機 CPU 上透過隨附的 ONNX Runtime 完成，不連網、不使用 GPU。
- 模型僅由引擎處理程序在背景非同步載入，一般候選、選詞、送出及詞庫補全無需等待載入完成。
- 單次語言模型呼叫限時 100 ms，長句 Tab 續寫限時 80 ms；逾時結果直接捨棄並保留既有結果。
- 推論執行緒數優先依高效能核心數決定，限制在 4 至 8 個；系統未提供核心分級資訊時，回退至實體或邏輯 CPU 數量。
- 僅讀取游標前最多 1,024 個 UTF-16 單元作為上下文，絕不讀取密碼欄位內容。

## 設定
可從選單列輸入選單開啟「设置…」，或按 Ctrl+Shift+F10 呼出；確認後的修改立即儲存並生效。

主要設定項目包括：
- 簡繁詞庫與拼音方案（全拼或 7 種雙拼之一）
- 逐項模糊音開關
- 每頁候選數（3 至 9）、翻頁鍵、補全鍵及 5 個可獨立啟用的功能快捷鍵
- 中英文切換鍵：Shift 或 Caps Lock（預設 Shift）
- 依應用程式獨立記住中英文狀態（預設開啟）
- 中文模式下的英文辨識（預設開啟）
- 數字後的句號自動轉為小數點（預設開啟）
- 中文標點模式下保持半形輸出的符號（預設為 Markdown 組合）
- 候選字型、字級、配色主題與可選的三行展開
- 候選視窗固定在輸入起點或跟隨游標（預設固定在起點）
- 以 `;` 和 `'` 選擇第二、第三個候選（預設關閉）
- 游標旁的中英文狀態提示氣泡（預設開啟）
- 自訂短語（新增／儲存修改、排序及 JSON 匯入／匯出）
- 進階頁：匯入其他輸入法的輸入頻次
- 進階頁：執行記錄檔開關（預設關閉；位於 `~/Library/Logs/CassotisIME/`）
- 進階頁：排序上文除錯顯示（預設關閉，獨立於記錄檔）

介面顯示偏好儲存在 `org.cassotis.inputmethod.Cassotis` 的 UserDefaults 中；引擎設定與學習資料位於 `~/Library/Application Support/CassotisIME/`。完整按鍵與選項說明請見[使用與設定（簡體中文）](CONFIGURATION.md)。

## 版本歷史

**v0.1.0（build 1，Windows v1.27.0）：首個公開發布版本。** 原生 InputMethodKit / AppKit 輸入法前端搭配獨立 Free Pascal 引擎處理程序、本機 ONNX 推論與簡繁詞庫；支援全拼、簡拼、6 種雙拼、模糊音、本機自學習與 Tab 補全；提供雙行候選視窗、8 套配色、游標旁狀態氣泡、即時生效的設定視窗及保留使用者資料的已簽章安裝程式。

**v0.2.0（build 2，Windows v1.29.0）：跨平台數值與排序對齊。** 引入結合上下文的短詞重排、長句書面短語復原、可選三行候選展開與跨行滑鼠選詞，以及僅在精確輸入時顯示的專業詞彙；對齊最小整數邊界比較與浮點中間精度語意，使 Apple 晶片下 Free Pascal 編譯的引擎與 Windows 版 Delphi 引擎輸出一致的候選路徑和分數。

**v1.0.0（build 3，Windows v1.31.0）：引入共用字元語言模型。** 以字元級語言模型取代原有的 RBT3 短上下文模型，統一承擔長句排序、上下文短詞消歧、混合簡拼與 Tab 續寫；支援短詞補全背景重排，以及長句下目前詞補全、後續短語與預測字元的綜合比較。

**v2.0.0（build 4，Windows v2.2.0）：單模型架構整合。** 將 v1.0.0 中按輸入階段拆分的 11 個神經網路圖整合為單一字元語言模型與 7 個輕量排序單元，全面移除舊模型圖、輔助索引與舊宿主程式碼。新增三至五音節詞庫外短語組句與同音修正，並加入中文模式英文辨識、U/I/V 快捷輸入、數字後自動小數點、Markdown 標點預設組合、依應用程式記憶中英文狀態及自訂短語。

**v2.1.0（build 5，Windows v2.4.0）：繁體模式接入語言模型。** 繁體候選與上下文映射為對應簡體交由模型評分，同時在候選顯示、翻頁、送出及 Tab 補全中維持臺灣常用繁體字形；新增外部輸入法詞頻匯入與排序上文除錯顯示。

**v2.5.0（build 6，Windows v2.5.0）：引入通用語料詞頻與版本號對齊。** 短詞排序引入通用語料詞頻特徵，提升無上下文時的常用詞首選率，並將詞間轉移改為依查詢按需讀取；支援單音節全量單字翻頁、Caps Lock 切換中英文，以及依高效能核心數配置模型執行緒。自本版本起，macOS 版與 Windows 版統一版本號。

**v2.6.0（build 7，Windows v2.6.0）：聯合評分修正與上下文短詞專有策略。** 拼音條件修正與語言模型聯合評分決定長句改寫，支援整詞同音替換；拆分獨立的帶上下文短詞決策模型（GBDT），無上下文單字改依現代字頻排序，並在完整音節單字後補充雙音節切分前綴字（如輸入 `shua` 時可選 `shu` 對應的字）。

**v2.7.0（build 8，Windows v2.7.0）：日常對話適配與全模式涵蓋。** 語言模型增量融合日常對話語料並重訓全部 6 個 GBDT 決策模型，無上下文時保護日常口語高頻首選；詞庫外短語組句與長句修正擴展至繁體及雙拼模式，新增帶上下文單字模型排序、長句二輪修正複查與智慧 ABC 雙拼。
